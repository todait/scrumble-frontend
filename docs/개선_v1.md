## 웹소켓 개선

⏺ 분석 결과, 현재 구조의 문제점과 개선 방안을 단계별로 제시하겠습니다.

🔍 현재 문제점

PostDetail.tsx:35에서 useCommentWebSocket(spaceSlug, post.id)를 호출하여 댓글 웹소켓을 구독하고 있습니다. 이는 PostDetail이 열렸을 때만 댓글 실시간 업데이트가 작동한다는 의미입니다.

FeedPage.tsx:46에서는 useWebSocket({ spaceSlug })로 일반적인 웹소켓만 연결하고 있어, 댓글 이벤트는 처리하지 않습니다.

📋 개선 작업 단계

1단계: 웹소켓 구독 구조 분석

- useCommentWebSocket 훅의 구현 내용 파악
- useWebSocket 훅과의 차이점 분석
- 댓글 이벤트 핸들러 로직 이해

2단계: 댓글 데이터 상태 관리 개선

- useFeedData 훅에서 댓글 데이터 포함 여부 확인
- React Query 캐시에서 댓글 데이터 업데이트 방식 검토
- 댓글 추가/삭제 시 피드 데이터 동기화 방안 설계

3단계: 웹소켓 구독 위치 변경

- FeedPage에서 전역적으로 댓글 웹소켓 구독하도록 수정
- 모든 포스트의 댓글 이벤트를 수신할 수 있도록 구조 개선
- PostDetail에서는 웹소켓 구독 제거하고 데이터만 사용

4단계: 댓글 이벤트 핸들러 통합

- FeedPage에서 댓글 이벤트 수신 시 해당 포스트의 댓글 데이터 업데이트
- PostDetail에서는 업데이트된 데이터를 props로 전달받아 사용
- 댓글 카운트 및 목록 실시간 동기화

5단계: 성능 최적화

- 불필요한 리렌더링 방지를 위한 메모이제이션 적용
- 댓글 이벤트 필터링 (현재 보고 있는 포스트만 UI 업데이트)
- 웹소켓 연결 최적화 (중복 구독 방지)

🎯 핵심 개선 포인트

1. 웹소켓 구독을 FeedPage로 이동: 전역에서 모든 댓글 이벤트 수신
2. 댓글 상태를 useFeedData에 통합: 중앙화된 데이터 관리
3. PostDetail을 순수 컴포넌트로 변경: 데이터 수신만 담당
4. 실시간 업데이트 로직 분리: 이벤트 핸들링과 UI 업데이트 분리

이러한 구조 개선을 통해 PostDetail이 닫혀있어도 댓글 데이터가 실시간으로 업데이트되고, PostDetail을 열었을 때 최신 댓글 데이터를 즉시 볼 수 있게 됩니다.

## 실시간 댓글 시스템 구조 개선 상세 내역 (2024.06)

### 1. 문제 배경 및 목표

- **문제**: 기존에는 PostDetail 모달이 열려 있을 때만 해당 포스트의 댓글 실시간 구독이 이루어져, 모달이 닫히면 실시간 댓글 반영이 중단됨.
- **목표**:
  - 피드 전체에서 실시간 댓글/리액션이 안정적으로 반영
  - 중복 구독/불필요한 네트워크 낭비 제거
  - 대규모 피드에서도 성능 저하 없이 동작
  - 타입 안정성 및 캐시 일관성 강화

### 2. 주요 개선 단계 및 핵심 코드

#### Phase 1: 구조 개선 (구독 위치 이동)

- **PostDetail.tsx**
  - 기존: `useCommentWebSocket(spaceSlug, post.id)`로 개별 모달마다 구독
  - 개선: **구독 로직 완전 제거**
    ```tsx
    // WebSocket 구독은 이제 FeedPage에서 전역적으로 관리됩니다
    ```
- **FeedPage.tsx**
  - **전역 WebSocket 구독** 및 댓글 이벤트 핸들러 등록
    ```tsx
    const { visiblePostIds, observePost } = useVisiblePosts();
    const { addEventListener, removeEventListener } = useWebSocket({ spaceSlug, visiblePostIds });
    useEffect(() => {
      addEventListener('comment.created', handleCommentCreated);
      addEventListener('comment.deleted', handleCommentDeletedEvent);
      return () => {
        removeEventListener('comment.created', handleCommentCreated);
        removeEventListener('comment.deleted', handleCommentDeletedEvent);
      };
    }, [addEventListener, removeEventListener]);
    ```
- **핵심 효과**:
  - PostDetail 모달이 닫혀도 피드 전체에서 실시간 댓글 반영
  - 중복 구독 제거, 메모리/네트워크 효율화

#### Phase 2: 성능/안정성 최적화

    - `visiblePostIds`가 바뀔 때마다 자동으로 구독/해제
    - 30초 지연 해제(스크롤 빠른 이동 시 깜빡임 방지)

  - WeakMap 기반 구독자 관리
  - 중복 구독 방지, 컴포넌트 언마운트 시 자동 정리
- **websocket.service.ts**
  - `batchSubscribeToComments`, `batchUnsubscribeFromComments` 등 배치 구독 지원
  - Heartbeat(ping/pong), 재연결, 에러 핸들링 강화
- **핵심 효과**:
  - 메모리 사용량, 네트워크 트래픽, 배터리 소모 대폭 감소
  - 대규모 피드에서도 안정적 실시간 동작
