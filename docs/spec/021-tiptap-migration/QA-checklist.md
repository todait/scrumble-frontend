## 알려진 이슈 및 제한사항

1. **플로팅 툴바 위치**

   - 에디터가 화면 상단에 있을 때 툴바가 에디터 밖으로 나갈 수 있음
   - → 향후 개선 필요

2. **모바일 플로팅 툴바**

   - 모바일에서 텍스트 선택 시 툴바가 키보드에 가려질 수 있음
   - → 향후 개선 필요

3. **이미지 inline 지원 안 함**
   - 현재 이미지는 에디터 외부에 별도 영역으로 표시
   - → Phase 2에서 고려
