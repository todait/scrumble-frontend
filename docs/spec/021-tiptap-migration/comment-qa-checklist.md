# Comment Tiptap Migration - QA Checklist

## 개요

CommentInput과 알림 Item에 Tiptap 에디터를 연동한 기능에 대한 QA 체크리스트입니다.

**테스트 환경**:
- [ ] 로컬 개발 환경
- [ ] 스테이징 환경
- [ ] 프로덕션 환경

**테스터**: _______________

---

## 1. CommentInput - 작성 기능

### 1.1 기본 입력

- [ ] **텍스트 입력**: 일반 텍스트 입력 가능
- [ ] **줄바꿈**: Shift+Enter로 줄바꿈 가능
- [ ] **Enter 제출**: Enter 키로 댓글 제출
- [ ] **한글 입력**: 한글 조합 중 Enter 처리 안전성
- [ ] **Placeholder**: 빈 상태에서 placeholder 표시

### 1.2 Rich Text 기능

- [ ] **Bold**: 텍스트 굵게
- [ ] **Italic**: 텍스트 기울임
- [ ] **링크**: URL 링크 삽입
- [ ] **리스트**: 불릿/번호 리스트
- [ ] **Code**: 인라인 코드
- [ ] **멘션**: @ 멘션 (향후 기능)

### 1.3 이미지 업로드

- [ ] **파일 선택**: 이미지 버튼 클릭 → 파일 선택 → 업로드
- [ ] **드래그앤드롭**: 이미지를 에디터 영역에 드롭
- [ ] **클립보드 붙여넣기**: Ctrl+V로 이미지 붙여넣기
- [ ] **업로드 진행**: 프로그레스바 표시
- [ ] **이미지 미리보기**: 업로드된 이미지 미리보기
- [ ] **이미지 삭제**: X 버튼으로 이미지 제거

### 1.4 제출 동작

- [ ] **빈 댓글 방지**: 텍스트와 이미지 모두 없으면 제출 버튼 비활성화
- [ ] **텍스트만**: 텍스트만 있을 때 제출 가능
- [ ] **이미지만**: 이미지만 있을 때 제출 가능
- [ ] **텍스트+이미지**: 텍스트와 이미지 함께 제출
- [ ] **제출 후 초기화**: 제출 후 에디터 및 이미지 초기화
- [ ] **제출 후 포커스**: 제출 후 에디터에 포커스 복귀

### 1.5 API 통신

- [ ] **content 필드**: plain text 전송 확인
- [ ] **content_json 필드**: Tiptap JSON 전송 확인
- [ ] **images 필드**: 이미지 메타데이터 전송
- [ ] **응답 처리**: 생성된 댓글 응답 정상 수신
- [ ] **에러 처리**: 네트워크 오류 시 적절한 에러 메시지

---

## 2. 댓글 렌더링 - 피드 상세

### 2.1 신규 댓글 (JSON 있음)

- [ ] **일반 텍스트**: 일반 텍스트 정상 표시
- [ ] **Bold/Italic**: 스타일 적용된 텍스트 표시
- [ ] **링크**: 클릭 가능한 링크 표시
- [ ] **리스트**: 불릿/번호 리스트 표시
- [ ] **줄바꿈**: 줄바꿈 정상 표시

### 2.2 기존 댓글 (JSON 없음)

- [ ] **Plain text fallback**: content 필드로 fallback 렌더링
- [ ] **줄바꿈 유지**: 기존 줄바꿈 정상 표시
- [ ] **스타일 없음**: 일반 텍스트로 표시

### 2.3 이미지 표시

- [ ] **이미지 렌더링**: 첨부된 이미지 정상 표시
- [ ] **이미지 클릭**: 이미지 클릭 시 확대/팝업
- [ ] **여러 이미지**: 다중 이미지 그리드 표시

### 2.4 API 응답 처리

- [ ] **content_json 있음**: JSON으로 렌더링
- [ ] **content_json stringified**: 파싱 후 렌더링
- [ ] **content_json 없음**: content로 fallback
- [ ] **content_json 손상**: fallback 동작 확인

---

## 3. 댓글 렌더링 - 알림 페이지 (CommentItem)

### 3.1 신규 댓글 알림

- [ ] **텍스트 추출**: JSON → plain text 추출
- [ ] **150자 truncate**: 긴 댓글 150자로 자르기
- [ ] **줄바꿈 제거**: truncate 시 줄바꿈 공백 처리
- [ ] **Bold/링크 제거**: plain text만 표시

### 3.2 기존 댓글 알림

- [ ] **Plain text 표시**: content 필드로 표시
- [ ] **150자 truncate**: 긴 댓글 150자로 자르기

### 3.3 알림 클릭

- [ ] **댓글 이동**: 알림 클릭 시 해당 댓글로 이동
- [ ] **댓글 하이라이트**: 이동 후 댓글 하이라이트

---

## 4. 엣지 케이스

### 4.1 빈 컨텐츠

- [ ] **빈 문자열**: content = "" 처리
- [ ] **빈 JSON**: contentJson = null 처리
- [ ] **빈 paragraph**: { type: 'doc', content: [{ type: 'paragraph' }] } 처리

### 4.2 특수 문자

- [ ] **이모지**: 😀😃😄 정상 표시
- [ ] **특수기호**: `< > & " '` 이스케이프 처리
- [ ] **긴 URL**: 긴 URL 줄바꿈/말줄임

### 4.3 대용량 데이터

- [ ] **긴 텍스트**: 10000자 이상 댓글 처리
- [ ] **많은 댓글**: 100개 이상 댓글 로딩
- [ ] **큰 이미지**: 10MB 이미지 업로드 제한

### 4.4 네트워크 오류

- [ ] **제출 실패**: 네트워크 오류 시 에러 메시지
- [ ] **타임아웃**: 타임아웃 시 재시도 옵션
- [ ] **오프라인**: 오프라인 상태 처리

---

## 5. 하위 호환성

### 5.1 기존 댓글 데이터

- [ ] **JSON 없는 댓글**: content만 있는 댓글 정상 표시
- [ ] **마이그레이션 전 댓글**: 기존 댓글 모두 정상 표시
- [ ] **혼합 상태**: JSON 있는 댓글과 없는 댓글 혼재 시 정상 표시

### 5.2 API 버전

- [ ] **백엔드 미지원**: content_json 지원 안 하는 백엔드와 호환
- [ ] **백엔드 지원**: content_json 지원하는 백엔드와 정상 동작
