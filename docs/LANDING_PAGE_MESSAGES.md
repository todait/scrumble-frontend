목표
• 핵심 KPI: 클로즈베타 신청 전환율(Visit→Submit) 극대화
• 보조 KPI: 제출 완료율(Submit→Success), ROI 섹션 스크롤 도달률, FAQ 노출 후 이탈률 감소

⸻

페이지 플로우(8 섹션 개선안)

1. IntroSection — 공감 극대화 + 스크롤 유도
   • 헤드라인: “오늘도 어김없이… 하루가 끝났나요?”
   • 롤링 메시지(2초 간격): 제공 리스트 그대로 표시. 마지막 메시지에 미세 진동 + 페이드로 감정 점.
   • 서브카피: “관리하느라 리더십을 못 쓰는 순간, 팀은 신호를 보냅니다.”
   • 프라이머리 CTA: “클로즈베타테스터 신청하기”
   • 보조 링크: “1분 데모 보기” (모달 영상/스크린샷)

2. CTASection — 가치 제안 + 신뢰 장치
   • 핵심문구: “Scrumble로 관리 시간을 절반으로 줄이고, 팀 리더 본연의 역할에 집중하세요.”
   • 강조 배지: “베타 한정 초대 • 선착순 10팀”
   • CTA: 동일 문구 재사용(일관성). 폼 앵커로 스크롤.

3. Section4 — 대비형 메시지(짧고 강하게)
   • 메시지: “관리 대신 전략에 / 보고 대신 결정에 집중”
   • 비주얼: 전/후 스플릿 카드(왼쪽 흐릿, 오른쪽 선명). 400~600ms 슬라이드 인.

4. Section5 — 기능 4대 중핵
   • 메인 문구: “관리가 아니라 리더십을. 팀을 움직이는 본질에 집중하세요.”
   • 기능 타일(4): 1분 체크인 / 투두·체크아웃 / 팀 대시보드 / 리포트 자동화
   • 인터랙션: hover→미니툴팁(“어떻게 시간이 절반이 되나요?” 등)로 구체 이득 노출

5. Section6 — 이점 6가지(문제→효과)
   • 구조: 각 항목에 “문제 상황 1줄 → Scrumble로의 해결 1줄”
   • 마이크로카피: “설득 비용 제로, 기존 툴에 살짝 추가”를 강조하여 도입 장벽 낮춤
   • 보조 CTA: “우리 팀에 맞는지 30초 체크” (간단 설문→폼 미리채움)

6. Section7 — Before/After 스토리텔링
   • Before 리스트 vs After 리스트 카드 비교
   • 스크롤 진입 시: Before는 회색→After는 컬러로 페이드 전환

7. Section8 — ROI(탭/자동 전환 6초)
   • 탭 6개: 단축/집중/향상/절감/포착/소통
   • 기본값 8명, \*표기: “가정에 따른 추정치이며 팀 특성에 따라 달라질 수 있습니다.”
   • 하단 와우라인: “팀의 운영, 더 아무지게. 더 많은 시간을 ‘진짜 일’에.”

8. 마지막 설득 & 폼
   • 신뢰요소: 베타 참여 혜택(우선 온보딩/전용 채널/가격 혜택), 개인정보 최소 수집 표기
   • 폼 필드: 이메일, 팀 규모(셀렉트), 회사/팀명(선택), 현재 사용하는 툴(선택)
   • 안심 카피: “신용카드 불필요 · 언제든 철회 가능”
   • 성공 상태: 감사 메시지 + 온보딩 대기 안내 + 공유 버튼

# 스크럼블 랜딩 페이지 메시지 가이드

## 개요

스크럼블 랜딩 페이지는 8개 섹션으로 구성되며, 각 섹션은 고유한 메시지 전략과 감정적 호소를 통해 팀 리더들의 공감을 이끌어내고 제품의 가치를 전달합니다.

## 섹션별 메시지 분석

### 섹션 1: 감정적 공감대 형성 (IntroSection)

**성격**: 공감 유도형 메시지
**핵심 메시지**: "오늘도 어김없이... 하루가 끝났나요?"

**롤링 메시지 (2초 간격)**:

- "장황한 회의만 하다가" 😵‍💫 😅
- "팀원들 상태 확인하다가" 😯 👀
- "일일이 확인하려 다니다가" 😬 😞
- "중요한 일은 또 밀리다가" 😬 😞
- "팀의 온도를 모르고" 😖 😵‍💫
- "팀원의 표정만 살피다" 😥 😯
- "지쳐버린 마음으로" 😭 😖
- "리더십 발휘는 언데간데 없이" 😰 😵
- "누군가의 신호를 놓친채" 🤯 😞

**전략**: 리더들이 일상적으로 겪는 피로감과 좌절감을 시각적, 감정적으로 표현하여 즉각적인 공감대 형성

---

### 섹션 2: 솔루션 제시 및 행동 유도 (CTASection)

**성격**: 가치 제안형 메시지
**핵심 메시지**:

- "Scrumble로 관리 시간을 절반으로 줄이고"
- "팀 리더 본연의 역할에 집중하세요."

**CTA**: "클로즈베타테스터 신청하기"

**전략**: 명확한 가치 제안(시간 절감 50%)과 리더의 본질적 역할 회복 약속

---

### 섹션 3: 핵심 가치 선언 (Section4)

**성격**: 대비형 메시지
**핵심 메시지**:

- "관리 대신 **전략에**"
- "보고 대신 **결정에 집중**"

**전략**: 간결한 대비 구조로 제품이 가져올 변화를 명확히 전달

---

### 섹션 4: 제품 기능 소개 (Section5)

**성격**: 기능 중심 메시지
**메인 메시지**:

- "관리가 아니라 리더십을."
- "팀을 움직이는 본질에 집중하세요."

**4대 핵심 기능**:

1. **1분 체크인**: "팀원 상태와 업무 상황을 빠르고 자연스럽게 파악"
2. **투두 및 체크아웃**: "업무 완료까지 흐름을 놓치지 않고 안정적으로 관리"
3. **팀 대시보드**: "진척도와 분위기를 한눈에 확인 놓치는 순간없이 즉각 대응"
4. **리포트 자동화**: "데이터 기반 인사이트 1:1 케어와 전략적 의사결정 지원"

---

### 섹션 5: 구체적 이점 제시 (Section6)

**성격**: 이점 중심 메시지
**메인 메시지**: "깊어지는 리더의 시간, 가벼워지는 팀의 움직임."

**6가지 구체적 이점**:

1. **장황한 회의, 체크인으로 대체**

   - "팀원 1분 작성, 리더는 대시보드 확인으로 끝"

2. **개인 할일이 팀에게 투명하게**

   - "누가 뭘 하고 있는지 투명하게 보여요"

3. **추측 그만, 데이터 기반 팀 관리**

   - "주간/월간 활동 패턴과 완료율을 객관적으로"

4. **팀원 케어 타이밍도 발빠르게**

   - "위험 신호를 빠르게 케어"

5. **상황 체크에 쏟는 시간, 초단축**

   - "대시보드만 보면 모든 팀원을 한눈에 파악"

6. **기존 툴과 자연스럽게 연동**
   - "팀원 설득 비용 제로, Scrumble만 살짝 추가"

---

### 섹션 6: Before/After 대비 (Section7)

**성격**: 변화 시각화 메시지
**메인 메시지**: "어제와는 다른 리더의 하루를 만드세요."

**Before (관리가 전부인 리더)**:

- 매일 팀원 상황 확인에 시간 소모
- 프로젝트 이슈를 늦게 발견
- 리더십 대신 관리 업무에 갇힘
- 팀 분위기 파악에 근거 부족
- 번아웃을 퇴사 통보로서야 알게 됨

**After (전략에 집중하는 리더)**:

- 팀 상황을 빠르게 한눈에 파악
- 빠른 이슈 감지와 즉각 대응 가능
- 전략과 팀 케어에 집중하는 리더십 발휘
- 데이터 기반으로 팀 상태와 분위기 관리
- 지속적인 케어로 팀원 번아웃 예방

---

### 섹션 7: ROI 및 구체적 성과 (Section8)

**성격**: 수치 기반 설득 메시지
**메인 메시지**: "팀의 운영, 더 아무지게. 더 많은 시간을 '진짜 일'에."

**6가지 ROI 지표 (탭 형식, 6초 자동 전환)**:

1. **단축 - 회의시간 80% 단축**

   - "30분 스탠드업을 1분 체크인으로"
   - \*8명 팀 기준 연 4.2억 절감 효과

2. **집중 - 금쪽같은 집중시간 2배 확보**

   - "확인하느라 DM도, 슬랙 뒤지기도 끝"

3. **향상 - 업무효율 60% 향상**

   - "보고를 위한 보고를 위한 작업은 최소로"

4. **절감 - 프로젝트 예산 15% 절감**

   - "일정 지연 신호를 미리 포착"
   - \*개발자 한 명만 지켜도 1.2억 원 손실 예방

5. **포착 - 팀원의 번아웃 조기 감지**

   - "팀을 잃지 않는 가장 빠른 방법"

6. **소통 - 자연스러운 소통 팀 에너지 개선**
   - "실시간으로 확인하는 우리 팀원들의 컨디션"

---

## 메시지 톤앤매너 분석

### 전체적인 톤

- **공감적**: 리더의 일상적 고민에 깊이 공감
- **솔루션 지향적**: 구체적인 해결책 제시
- **데이터 기반**: 명확한 수치와 ROI 제시
- **희망적**: 변화 가능성에 대한 긍정적 메시지

### 메시지 전개 구조

1. **공감** (섹션 1): 현재의 고통 인식
2. **해결** (섹션 2-3): 솔루션 제시
3. **방법** (섹션 4-5): 구체적 기능과 이점
4. **증명** (섹션 6-7): Before/After 비교
5. **가치** (섹션 8): ROI와 구체적 성과

### 주요 키워드

- **시간**: 절감, 단축, 집중
- **리더십**: 본연의 역할, 전략, 케어
- **효율**: 자동화, 한눈에, 즉각
- **팀**: 온도, 분위기, 연결

---

## 활용 가이드

### 마케팅 메시지 일관성

- 모든 마케팅 자료에서 "관리에서 리더십으로"라는 핵심 메시지 유지
- 구체적 수치(80% 시간 절감, 60% 효율 향상 등) 일관되게 사용

### 타겟 오디언스별 메시지 강조점

- **스타트업 리더**: 시간 절감, 효율성
- **중견기업 팀장**: 데이터 기반 관리, ROI
- **대기업 관리자**: 번아웃 예방, 팀 케어

### 감정 곡선

1. 시작: 피로감과 공감 (낮은 감정)
2. 중간: 희망과 가능성 (상승하는 감정)
3. 끝: 확신과 행동 유도 (높은 감정)

4. FeatureGrid(Section5, 4타일)

- 리포트 자동화: "데이터 기반 인사이트로 1:1 케어·전략적 의사결정"

5. Benefits(Section6, 6개)

6. BeforeAfter(Section7)

7. ROI Tabs + Calculator(Section8)

- 탭: 단축/집중/향상/절감/포착/소통 (6초 자동 전환)
- “30분 스탠드업을 1분 체크인으로” 등 제공 카피 사용

- 주석: "\*가정에 따른 추정치이며 팀 특성에 따라 달라질 수 있습니다."
- 하단 문구: "팀의 운영, 더 아무지게. 더 많은 시간을 '진짜 일'에."

9. FAQ

10. StickyCTA + Exit

- 스크롤 30% 이후 하단 고정 CTA

11. BetaForm

- 필드: 이메일(필수), 팀 규모(필수), 회사/팀명(선택), 사용 중인 툴(선택)
- 안심 카피: "신용카드 불필요 · 언제든 철회 가능"
- 성공 상태: 감사 메시지 + 다음 단계 안내

[상호작용/애니메이션]

- 롤링 텍스트 2s, 탭 자동 전환 6s, 요소 페이드/슬라이드 300~600ms
- 성능 우선(이미지 lazy, WebP, 폰트 서브셋)
- 섹션별 페이지가 차지하는 거 아님 (쭉 스크롤 되게끔 처리)

- CTA 문구 일관: "클로즈베타테스터 신청하기"

[테마/스타일]

- text 기본 #1D1D1F, Primary Color #9747FF
- 카드 라운드, 소프트 섀도, 충분한 여백

- 더미 이미지/아이콘 포함
